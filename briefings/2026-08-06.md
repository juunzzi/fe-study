## 스택 업데이트

### Next.js 16.2.10 → 16.3 ([릴리스 노트](https://nextjs.org/blog/next-16-3), 2026-08-03)
- dev 서버 메모리 최대 90% 절감(디스크 캐시+메모리 eviction 기본 활성), 반복 빌드 파일시스템 캐시로 최대 5.5x 빠른 CI 빌드.
- App Router SSR을 web streams → Node.js 네이티브 스트림으로 교체, 부하 시 처리량 +22% (코드 변경 불필요).
- **Instant Navigations**(옵트인: `cacheComponents` + `partialPrefetching`): SPA급 전환 반응성, Instant Insights 데브툴, Playwright `instant()` 테스트 헬퍼.
- `catchError` 커스텀 에러 바운더리(retry로 실패한 서버 컴포넌트 재요청), root params(`next/root-params`), `import.meta.glob`.
- **immutable static assets를 배포 간 재사용**하는 옵션 추가 — 롤링 배포 중 청크 혼재(version skew) 문제와 직접 관련.
- 실험 기능: **Rust판 React Compiler**(Turbopack 내장, cold 34%/warm 46% 빠름), `useOffline` 네트워크 복원력.
- 우리 레포 영향: 16.2.10 → 16.3은 마이너라 breaking 없음. React Compiler 사용 중이므로 Rust 컴파일러 실험 플래그가 dev 속도에 직접 이득 가능. FE-1145에서 다룬 version skew 대응책으로 immutable assets 옵션 검토 가치.

### TypeScript 6.0.3 → 7.0 ([공식 발표](https://devblogs.microsoft.com/typescript/announcing-typescript-7-0/), [InfoQ](https://www.infoq.com/news/2026/08/typescript-7-released/))
- JS 구현을 Go 네이티브로 포팅한 첫 정식판. 풀 빌드 8~12x 속도 향상(VS Code 소스 기준 125.7s → 10.6s), 메모리 ~18% 절감.
- Next 16.3이 `next build` 타입체크에 TS7 사용을 공식 지원(`typescript@^7` 설치만으로).
- 우리 레포 영향: 메이저 업그레이드라 CI 타입체크 시간 단축 폭이 크지만, 컴파일러 교체라 에코시스템(eslint parser, 빌드 플러그인) 호환 확인 필요. 당장 급하진 않고 검토 대상.
